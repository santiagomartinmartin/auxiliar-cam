# Auxiliar Administrativo C2 · Comunidad de Madrid

Web de estudio para la oposición de Auxiliares de Administración General (C2) de la Comunidad de Madrid (Orden 1628/2026).

- 21 temas del programa (Anexo III) con desarrollo, resumen y banco de preguntas.
- Exámenes oficiales de convocatorias anteriores y simulacros cronometrados con el formato del examen.
- El progreso se guarda en el navegador.
