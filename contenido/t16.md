# Tema 16. El explorador de Windows. Gestión de carpetas y archivos. Operaciones de búsqueda. Herramientas «Este equipo» y «Acceso rápido». Accesorios. Herramientas del sistema

> **Versión de referencia:** el examen se hace sobre **Windows 11**. Muchas preguntas de convocatorias anteriores se redactaron para **Windows 10**; la lógica es casi igual, pero cambian algunos nombres y la apariencia (sobre todo la **cinta de opciones**, sustituida por una **barra de comandos**).

## 1. El Explorador de archivos

### 1.1. Abrirlo

- **Windows + E**.
- Icono de carpeta de la **barra de tareas** o del menú **Inicio**.
- Botón derecho sobre **Inicio** → **Explorador de archivos**.

### 1.2. Partes de la ventana (Windows 11)

| Elemento | Para qué sirve |
|---|---|
| **Pestañas** | Varias carpetas en la misma ventana (**Ctrl + T** abre una pestaña nueva, **Ctrl + W** la cierra) |
| **Barra de direcciones** | Muestra la **ruta completa** de la carpeta actual (cada tramo es pulsable); se puede escribir una ruta |
| **Cuadro de búsqueda** | Busca en la carpeta actual y sus subcarpetas |
| **Barra de comandos** | **Nuevo**, **Cortar, Copiar, Pegar, Cambiar nombre, Compartir, Eliminar**, **Ordenar**, **Ver** y **Ver más (…)**. Sustituye a la cinta de opciones de Windows 10 |
| **Panel de navegación** (izquierda) | **Inicio**, **Galería**, **OneDrive**, carpetas ancladas, **Este equipo**, **Red** |
| **Área de contenido** | Archivos y carpetas de la ubicación actual |
| **Panel de vista previa** (**Alt + P**) | Muestra el contenido de un archivo **sin abrirlo** (documentos, imágenes, PDF…) |
| **Panel de detalles** (**Alt + Mayús + P**) | Propiedades del elemento seleccionado (tamaño, fechas, autor…) |
| **Barra de estado** | Número de elementos y elementos seleccionados |

### 1.3. Vistas, orden y agrupación

- **Ver:** iconos muy grandes, grandes, medianos y pequeños; **lista**; **detalles** (columnas de nombre, fecha, tipo y tamaño); **mosaicos**; **contenido**. También **Vista compacta** y mostrar u ocultar **extensiones**, **elementos ocultos** y **casillas** de selección.
- **Ordenar** por nombre, fecha, tipo, tamaño… (ascendente o descendente).
- **Agrupar por** tipo, fecha, etc.: el **número entre paréntesis** junto a cada grupo indica **cuántos archivos tiene ese grupo**.
- **Opciones de carpeta** (Ver más → Opciones): abrir en «Inicio» o «Este equipo», un clic o doble clic, privacidad del historial, mostrar extensiones, etc.

### 1.4. Inicio y Acceso rápido

En Windows 11 la página de entrada del Explorador se llama **Inicio** (en Windows 10 era **Acceso rápido**). Contiene:

- **Acceso rápido:** carpetas **ancladas** y carpetas **frecuentes**.
  - Una carpeta **anclada** permanece siempre visible, **con independencia** de la frecuencia de uso (botón derecho → **Anclar a Acceso rápido**).
  - Las carpetas **frecuentes** aparecen y desaparecen solas según el uso.
- **Favoritos:** archivos marcados como favoritos (también los de Microsoft 365).
- **Recientes:** archivos abiertos recientemente. Se pueden **borrar** desde las opciones de privacidad.

Las carpetas ancladas aparecen también en el **panel de navegación**.

### 1.5. Este equipo

**Este equipo** muestra las **unidades de almacenamiento** (discos internos, USB, lectores, unidades de red asignadas) y las carpetas principales del usuario. Desde aquí:

- Se ve el **espacio libre y total** de cada unidad (barra de capacidad bajo cada disco y en sus **Propiedades**).
- Se **asignan o desconectan unidades de red** (Ver más → **Conectar unidad de red**).
- Se accede a las **propiedades del sistema**.

## 2. Gestión de archivos y carpetas

### 2.1. Conceptos

- **Archivo:** conjunto de información con un **nombre** y una **extensión** (normalmente **3 o 4 caracteres** tras el último punto: `.docx`, `.xlsx`, `.pdf`, `.jpg`) que indica su **tipo** y la aplicación que lo abre.
- **Carpeta:** contenedor de archivos y otras carpetas (**subcarpetas**), organizados en un **árbol**.
- **Ruta:** ubicación completa, por ejemplo `C:\Usuarios\Ana\Documentos\informe.docx`.
- **Carpeta personal:** Windows crea una para **cada usuario** (`C:\Usuarios\<nombre>`), con **Escritorio, Documentos, Descargas, Imágenes, Música y Vídeos**.
- **Nombres:** no pueden contener `\ / : * ? " < > |`.
- **Acceso directo:** icono con una **flecha** que apunta a un archivo, carpeta o programa; borrarlo **no** borra el original.

### 2.2. Operaciones básicas

| Operación | Cómo |
|---|---|
| **Nueva carpeta** | Nuevo → Carpeta, o **Ctrl + Mayús + N** |
| **Cambiar nombre** | **F2**, o botón derecho → Cambiar nombre |
| **Copiar / Cortar / Pegar** | **Ctrl + C / Ctrl + X / Ctrl + V** |
| **Deshacer / Rehacer** | **Ctrl + Z / Ctrl + Y** |
| **Seleccionar todo** | **Ctrl + A** en el Explorador (ojo: en **Office en español** es **Ctrl + E**) |
| **Selección múltiple** | **Ctrl + clic** (elementos sueltos) o **Mayús + clic** (rango) |
| **Eliminar a la Papelera** | **Supr** |
| **Eliminar definitivamente** | **Mayús + Supr** (no pasa por la Papelera) |
| **Propiedades** | **Alt + Entrar**, o botón derecho → Propiedades |
| **Abrir con** | Botón derecho → Abrir con. Si un tipo de archivo **no tiene aplicación asociada**, Windows muestra «**¿Cómo quieres abrir este archivo?**» |

**Arrastrar y soltar:**

- En la **misma unidad**: **mueve**. A **otra unidad**: **copia**.
- **Ctrl** mientras se arrastra: **copia** · **Mayús**: **mueve** · **Alt**: crea un **acceso directo**.

### 2.3. La Papelera de reciclaje

- Guarda lo eliminado de los discos locales hasta que se **vacía**. Desde ella se puede **restaurar** a la ubicación original.
- Lo borrado de **unidades USB** o de **red** normalmente **no** pasa por la Papelera.

### 2.4. Propiedades y atributos

- **Solo lectura:** intenta evitar **modificaciones o sobrescrituras** accidentales (no impide borrar ni copiar el archivo).
- **Oculto:** no se muestra salvo que se active «Elementos ocultos».
- **Avanzados:** **comprimir** el contenido para ahorrar espacio y **cifrar** (EFS, en las ediciones Pro y superiores).
- Pestañas de **Seguridad** (permisos NTFS), **Detalles** (metadatos) y **Versiones anteriores**.

### 2.5. Comprimir y compartir

- **Comprimir:** botón derecho → **Comprimir en archivo ZIP**. Windows 11 también **extrae** archivos `.7z`, `.rar` o `.tar`, y en las versiones recientes puede **crear** `.7z` y `.tar`.
- **Compartir:** botón **Compartir** (correo, aplicaciones, **Compartir en proximidad** con equipos cercanos) o **Propiedades → Compartir** para dar acceso a la carpeta a **otros usuarios de la red**. Con **OneDrive**, se comparte un **vínculo**.

### 2.6. Dispositivos extraíbles

Antes de desconectar una memoria USB conviene **Quitar hardware de forma segura** (icono de la bandeja del sistema o **Expulsar** en el Explorador) para **evitar la pérdida de datos** si hay escrituras pendientes.

## 3. Operaciones de búsqueda

- El **cuadro de búsqueda** del Explorador busca en la **carpeta actual y sus subcarpetas**, por **nombre** y por **contenido** (si la ubicación está **indexada**).
- La **búsqueda de Windows** (Windows + S o el cuadro de la barra de tareas) busca en todo el equipo, aplicaciones, configuración y web.
- La **indexación** se configura en **Configuración → Privacidad y seguridad → Buscar en Windows** (modo **Clásico**, solo bibliotecas y escritorio, o **Mejorado**, todo el equipo).

| Técnica | Ejemplo | Efecto |
|---|---|---|
| **Comillas** | `"informe anual"` | Busca la **frase exacta** |
| **Comodín \*** | `inf*` | Cualquier número de caracteres |
| **Comodín ?** | `inf?rme` | Un solo carácter |
| **AND / OR / NOT** | `informe NOT borrador` | Operadores lógicos (en mayúsculas) |
| **kind: / tipo:** | `kind:document`, `kind:picture` | Archivos de una **categoría** (documentos, imágenes, música, vídeo…) |
| **ext:** | `ext:pdf` | Por **extensión** |
| **size: / tamaño:** | `size:large`, `size:>10MB` | Por **tamaño** |
| **datemodified: / fechademodificación:** | `datemodified:this week` | Por **fecha** |
| **author: / name:** | `author:Ana` | Por **autor** o **nombre** |

Tras buscar, el Explorador permite **refinar** con filtros (tipo, fecha, tamaño) y **guardar la búsqueda**.

## 4. Accesorios de Windows 11

| Accesorio | Uso |
|---|---|
| **Bloc de notas** | Editor de **texto plano** (`.txt`). En Windows 11 tiene **pestañas** y, en las versiones más recientes, un **formato básico** opcional |
| **WordPad** | Editor de **texto enriquecido** (`.rtf`): permitía negrita, cursiva, imágenes… **Eliminado en Windows 11 24H2** (sigue apareciendo en preguntas antiguas) |
| **Paint** | Dibujo y edición sencilla de imágenes (capas, quitar fondo) |
| **Recortes** | **Capturas de pantalla** y grabaciones (**Windows + Mayús + S**); sustituye a la antigua herramienta Recortes y a «Recortes y anotaciones» |
| **Calculadora** | Estándar, científica, programador, gráficos, conversión de unidades |
| **Mapa de caracteres** | **Insertar símbolos y caracteres especiales** que no están en el teclado |
| **Reloj** | Alarmas, temporizador, cronómetro y sesiones de concentración |
| **Grabadora de sonido** | Grabar audio |
| **Fotos / Reproductor multimedia** | Ver imágenes y reproducir audio y vídeo |
| **Conexión a Escritorio remoto** | Controlar otro equipo por la red |
| **Accesibilidad** | **Lupa** (**Windows + +**), **Narrador** (**Ctrl + Windows + Entrar**), **Teclado en pantalla**, **Acceso por voz** |

## 5. Herramientas del sistema

En Windows 11 se agrupan en **Inicio → Todas las aplicaciones → Herramientas de Windows** (antes, «Herramientas administrativas») y en **Configuración**.

| Herramienta | Para qué sirve | Acceso directo |
|---|---|---|
| **Administrador de tareas** | Ver en **tiempo real** procesos, rendimiento, aplicaciones de inicio y servicios; finalizar tareas | **Ctrl + Mayús + Esc** |
| **Liberador de espacio en disco** | **Eliminar archivos innecesarios** (temporales, Papelera, actualizaciones antiguas) | `cleanmgr` |
| **Sensor de almacenamiento** | Liberar espacio **automáticamente** (Configuración → Sistema → Almacenamiento) | — |
| **Desfragmentar y optimizar unidades** | **Reorganizar** los datos de los discos duros (HDD) para mejorar el rendimiento; en los SSD ejecuta **TRIM** | `dfrgui` |
| **Administración de discos** | Particiones, formato, letras de unidad | `diskmgmt.msc` |
| **Administrador de dispositivos** | Hardware y controladores | `devmgmt.msc` |
| **Servicios** | Iniciar, detener y configurar servicios | `services.msc` |
| **Programador de tareas** | Ejecutar tareas automáticamente | `taskschd.msc` |
| **Visor de eventos** | Registros del sistema y de las aplicaciones | `eventvwr.msc` |
| **Monitor de recursos / de rendimiento** | Consumo de CPU, memoria, disco y red | `resmon` / `perfmon` |
| **Información del sistema** | Hardware y software instalados | `msinfo32` |
| **Configuración del sistema** | Opciones de arranque y servicios | `msconfig` |
| **Restaurar sistema** | Volver a un **punto de restauración** anterior. Afecta a **aplicaciones, controladores, actualizaciones y configuración**, pero **no a los documentos personales** | `rstrui` |
| **Copias de seguridad** | **Historial de archivos** y **Copia de seguridad de Windows** (con OneDrive) | — |
| **Seguridad de Windows** | Antivirus (Microsoft Defender), firewall, protección del dispositivo | — |
| **Windows Update** | Actualizaciones (Configuración → Windows Update) | — |
| **Panel de control** | Configuración clásica (sigue existiendo junto a Configuración) | `control` |

> **Diferencia clásica:** el **Liberador de espacio** **elimina** archivos innecesarios; el **Desfragmentador** **reorganiza** los datos del disco. Ninguno de los dos crea puntos de restauración.
