# Tema 16 · Resumen y trampas

## Lo imprescindible

- **Explorador de archivos:** **Windows + E**. En Windows 11 tiene **pestañas**, **barra de comandos** (sustituye a la cinta) y panel de navegación con **Inicio**, **Galería**, **OneDrive**, **Este equipo** y **Red**.
- **Barra de direcciones** = **ruta completa**. **Panel de vista previa** (Alt + P) = ver el contenido **sin abrir** el archivo. **Panel de detalles** = propiedades.
- **Inicio / Acceso rápido:** carpetas **ancladas** (siempre visibles) y **frecuentes** (cambian según el uso); **Favoritos** y **Recientes**.
- **Este equipo:** **unidades de almacenamiento** y carpetas principales; **espacio libre** de cada unidad; **conectar unidad de red**.
- **Extensión:** 3 o 4 caracteres tras el punto que indican el **tipo** de archivo.
- **Carpeta personal:** una por **usuario** (`C:\Usuarios\nombre`).
- **Solo lectura:** intenta evitar **modificaciones**; **Oculto:** no se muestra.
- **Restaurar sistema:** **no afecta a los documentos personales**.
- **Liberador de espacio:** **elimina** archivos innecesarios. **Desfragmentador:** **reorganiza** los datos del disco.
- **Administrador de tareas** (Ctrl + Mayús + Esc): procesos **en tiempo real**.
- **Mapa de caracteres:** insertar **símbolos especiales**. **Bloc de notas:** texto **sin formato**; **WordPad** (texto enriquecido) se eliminó en Windows 11 24H2.

## Atajos y operadores

| Atajo / operador | Efecto |
|---|---|
| **Supr / Mayús + Supr** | A la Papelera / **borrado definitivo** |
| **F2** | Cambiar nombre |
| **Ctrl + Mayús + N** | Nueva carpeta |
| **Alt + Entrar** | Propiedades |
| **Ctrl / Mayús / Alt al arrastrar** | **Copiar / mover / acceso directo** |
| **"frase"** | Frase exacta |
| **kind:** | Archivos de una **categoría** (documento, imagen…) |
| **ext:** | Por **extensión** |
| `diskmgmt.msc` · `devmgmt.msc` · `services.msc` · `taskschd.msc` | Administración de discos · Administrador de dispositivos · Servicios · Programador de tareas |

## Trampas habituales

- Arrastrar en la **misma unidad** mueve; a **otra unidad**, copia.
- Al **agrupar**, el número entre paréntesis es el **número de archivos** del grupo.
- Un archivo **sin aplicación asociada** muestra «**¿Cómo quieres abrir este archivo?**».
- **Quitar hardware de forma segura** sirve para **evitar la pérdida de datos**.
- En Windows 11 el antiguo «Acceso rápido» se llama **Inicio** en el panel de navegación, pero se sigue **anclando a Acceso rápido**.
